# Seed assets

Datos y archivos usados por `npm run seed`.

| Ruta | Uso |
|------|-----|
| `inspectors.xlsx` | Planilla fuente de inspectores (nombre, RUT, celular, régimen). |
| `inspectors.json` | Misma lista en JSON (la lee el seed). Actualizar ambos al cambiar la planilla. |
| `multimedia/` | Retratos y futuros documentos para avatares/adjuntos del seed. |
